# GT Помощник

Личная программа для Windows: чат для работы с плиткой Golden Tile и планировщик задач.

- План и список сделанного — PLAN.md
- Запуск из исходников: `npm install`, затем `npm start`
- Сборка установщика (на Windows): `npm run dist` → папка dist
- Данные пользователя (задачи, журнал, копии файла) лежат отдельно от программы — в «папке данных» из Настроек
